# Istruzioni per gli agenti AI

Prima di intervenire sul progetto, leggi [journal-ai.md](./journal-ai.md): è la
memoria condivisa delle istruzioni dell'utente, delle decisioni e del lavoro in
corso.

Per ogni richiesta relativa al progetto:

1. Consulta il journal prima di pianificare o modificare file.
2. Aggiorna `journal-ai.md` dopo aver ricevuto nuove istruzioni o decisioni e
   prima di concludere il turno. Registra in modo conciso obiettivo, stato,
   decisioni, file interessati e verifiche effettivamente eseguite.
3. Lascia chiaro cosa è completato, cosa è in corso e il prossimo passo, così
   un altro agente può riprendere senza ricostruire la chat.
4. Non dichiarare verifiche o attività completate se non lo sono; non inserire
   nel journal credenziali o altri dati sensibili.
5. Se deleghi parte del lavoro, passa all'agente il contesto pertinente del
   journal; l'agente coordinatore integra nel journal i risultati ricevuti.

Mantieni le istruzioni e lo stato aggiornati senza cancellare le preferenze
precedenti dell'utente. Scrivi in italiano, salvo diversa richiesta.
